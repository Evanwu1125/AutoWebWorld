## FSM to React Mapping

The FSM JSON defines the application's page structure and interactions:

- **`meta.initial_page_id`** → The default/home route
- **`meta.terminal_pages`** → Success/completion pages
- **Each `pages[]` entry** → A React page component file in `src/pages/<page.id>.jsx`
  - `page.id` → Filename and route identifier
  - `page.signature_schema` → Local state for that page (use `useState`)
  - `page.actions[]` → Interactive elements on the page

- **Each `action`** → A UI element:
  - `action.name == "click"` + `is_navigation == true` → Navigation button/link
  - `action.name == "click"` + `is_navigation == false` → In-page action button (modal dismiss, toggle, etc.)
  - `action.name == "type"` → Text input field
  - `action.name == "search"` → Search input with submit
  - `action.name == "select"` → Dropdown, date picker, slider, etc.

- **`action.gui_procedure`** → Determines the UI widget type and selectors:
  - `gui_procedure[].selector` → Use as the element's `id` or `className` (strip the `#` or `.` prefix)
  - Example: `selector: "#nav-signin"` → `<button id="nav-signin">`

- **`action.to`** → Navigation target page when `is_navigation == true`
